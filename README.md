# markusmo3.github.io

This repository contains a simple redirect page that forwards all visitors to my GitHub profile.

## What it does

When you visit [markusmo3.github.io](https://markusmo3.github.io), you'll be automatically redirected to [github.com/markusmo3](https://github.com/markusmo3).

## Implementation

The redirect is implemented in `index.html` using:
- HTTP meta refresh tag for automatic redirection
- JavaScript redirect as a fallback
- Manual link for browsers that don't support automatic redirects
